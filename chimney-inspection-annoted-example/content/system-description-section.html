System Description Section

The system description section documents what type of chimney system was inspected.

Key System Information

  • Appliance Type: Masonry fireplace, wood stove, gas insert, etc.
  • Fuel Type: Solid fuel, natural gas, propane, oil
  • Venting Method: Natural draft, direct vent, power vent
  • Flue Liner Type: Clay tile, stainless steel liner, cast-in-place, unlined
  • Chimney Construction: Masonry, factory-built, metal
  • Chimney Location: Interior or exterior

Why Document the System

Different chimney types have different requirements and potential issues. Documenting the system type:

  • Sets context for findings
  • Helps identify applicable codes and standards
  • Supports future inspections and comparisons
  • Clarifies what was actually evaluated
