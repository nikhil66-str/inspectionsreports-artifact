Report Sections Overview

Standard Report Components

  1. Property Information - Address, client details, report number
  2. Inspection Scope - Level 2 requirements and areas covered
  3. Video Scan Documentation - Flue interior findings
  4. Clearance Verification - Combustible clearances
  5. Photo Documentation - Visual evidence of conditions
  6. Summary of Findings - Categorized observations
  7. Recommendations - Required and suggested actions
  8. Limitations & Disclaimers - Scope boundaries
  9. Inspector Certification - Signatures and credentials

Property Information

Essential identification including:

  • Property address
  • Inspection date
  • Client name and contact
  • Report reference number

Findings Categories

Findings are typically categorized as:

  • Satisfactory - Meets standards, no action required
  • Requires Attention - Maintenance or monitoring recommended
  • Deficient - Repairs required before safe operation
