Defect Documentation Examples

When defects are found, detailed documentation is essential for client communication and legal protection.

Defect Documentation Checklist

  • Specific location of the defect
  • Nature and type of defect
  • Severity classification
  • Potential consequences if not addressed
  • Recommended corrective action
  • Photo reference numbers

Example Defect Descriptions

Minor Issue: "Light creosote deposits (Stage 1) observed on flue liner walls. Recommend cleaning before next heating season. See Photo 4."

Moderate Issue: "Hairline crack observed in clay tile liner at approximately 8 feet from firebox. Crack appears stable. Recommend monitoring at next annual inspection. See Photo 7."

Serious Issue: "Significant tile displacement observed at smoke chamber transition. Gap exceeds acceptable limits per NFPA 211. System should not be used until repaired by qualified professional. See Photos 9-11."
